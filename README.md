# pinneapple-labs-site

Landing page for **PINNeAPPle Labs** — open-source Physics AI with verification as part of the product.

Static site, no build step. Served at <https://pinneapple-labs.github.io/>.

## Structure

| Path | What it is |
|---|---|
| `index.html` | Portuguese page (pt-BR), the default |
| `en/index.html` | English page |
| `styles.css` | The whole design system: tokens, layout, components |
| `app.js` | Nav toggle, copy-to-clipboard, code tabs, scroll reveal, section spy |
| `fonts.css`, `fonts/` | Self-hosted Archivo + JetBrains Mono (latin subset, OFL) |
| `img/` | Portfolio and capability stills; `img/results/` holds real result plots |
| `img/results/` | Figures generated by the PINNeAPPle benchmarks and examples |
| `videos/` | Hero video (OpenFOAM skin pressure) and two demo clips |
| `Dockerfile` | nginx image serving the tree, for a self-hosted deploy |

## Editing

Both language pages share `styles.css` and `app.js`. If you change markup, change it in
`index.html` and `en/index.html` together — asset paths in the English page are prefixed
with `../`.

The install command in the hero is a `<button class="install" data-copy="…">`; changing
`data-copy` changes what gets copied.

## Deploying

GitHub Pages: push to `main` and set **Settings → Pages → Source** to `main` / root.
`.nojekyll` is present so nothing gets filtered.

Self-hosted:

```bash
docker build -t pinneapple-labs-site .
docker run --rm -p 8080:80 pinneapple-labs-site
```

## Content rule

Every number on the page is traceable to a run in the PINNeAPPle repository or to a
published reference (Vieira et al. 2016, Ghia et al., Bekker–Wong). When a claim has a
limit, the limit is written next to it. Do not add a metric without a source.

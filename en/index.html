The problem

Why simulation holds the project up

It is not a lack of software. It is time, cost and — mostly — trust in the number that comes out.

The deadline

A week to build the case, another to run it, another to check it. By the time the result lands, the decision was already made on a guess.

The cost

Licence, idle machine and a specialist. Sometimes the simulation costs more than the decision it was meant to support.

The trust

The result comes out colourful and pretty, and nobody knows whether it is right. Without an external reference, the number is just an opinion.

Coming soon · 2027

PINNeAPPle Engineering

Engineering in text: you write what you need, and the platform finds a tool that already exists, checks whether your case sits inside what that tool has already proven, runs it, and returns the result with a report and evidence.

  • It understands the written request — no method name, no case to build.
  • It says plainly whether it covers you — “yes”, “this value is missing”, “partly” or “no”.
  • It only runs what has proof — every tool is discovered, tested or verified.
  • It hands back the report — what ran, what did not, and where each number came from.

How it works

Three steps, none of them technical

What today depends on someone who knows how to build the case becomes, tomorrow, a written sentence and a check.

01

You write the problem

In plain language: what you need, which material, what size, what limit. No method names and no configuration file.

02

The platform checks and chooses

It looks for a tool that already solves it, checks whether your numbers sit inside what it has proven, and says what is missing before running.

03

You get the result and the report

With the checks that ran, the ones that did not, the code version and what has not been proven yet.

Who makes it

One rule: if it has no measured number, it does not go on screen.

PINNeAPPle started as a personal library so its author would not have to take anything on trust: every result carries the reference it was checked against. It became a product when it was clear the problem is not the model — it is the lack of proof.

Saying “no” is part of it. In one rover-mobility case the classical numerical method was faster and more accurate than the network; the recommendation was the classical method.

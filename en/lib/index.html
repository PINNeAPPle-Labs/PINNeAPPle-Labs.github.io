Why this matters: the same library that trains the network also runs the reference solver. Comparing a model against itself is the most common mistake in Physics AI — here the reference is always external to training.
inverse_heat.py
# the h nobody measures, from a handful of thermocouples
from pinneapple_physics import HeatConduction1D
from pinneapple_neural import PINNTrainer

problem = HeatConduction1D(conductivity=50.0, length=0.30, learn_h=True)
model = PINNTrainer(problem, layers=[3, 64, 64, 1])
report = model.fit(thermocouples=readings, epochs=5000)

print(report.h, report.h_std)         # 14.8 0.3  (true value: 15)
report.verify_against("finite-volume")  # per-field error, error map

What you get on day one

  • A reproducible environment — 248 examples with versioned output, to compare against your own result.
  • Public benchmarks — SSQN Helmholtz, LBM vortex shedding, LPM design space, latency and I/O.
  • Real interoperability — OpenFOAM, CalculiX, FEniCS/dolfinx, Gmsh, VTK, STL, USD and glTF in one session.
  • Industry standards — AAS, DTDL, NGSI-LD, Eclipse Ditto and OPC UA for what the plant already consumes.
